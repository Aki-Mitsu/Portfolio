## Site Navigation
 
The portfolio is a single scrolling page. Scroll down to move through the sections in this order:
 
1. **Homepage:** introduction and social media links.
2. **About:** personal information and photo.
3. **Projects:** project descriptions with links to GitHub and live demos.
4. **Skills:** programming languages, web development, and version control.
5. **Contact:** contact information, social links, and the **Get in Touch** button.
## Getting Started
 
You can view the portfolio online at **[Aki-Mitsu.github.io/Portfolio](https://Aki-Mitsu.github.io/Portfolio/)**.
 
To run it locally:
 
1. Clone the repository:
```bash
git clone https://github.com/akimits25/Portfolio.git
```
2. Navigate into the project folder:
```bash
cd Portfolio
```
3. Open `index.html` in your browser.
